Grounding Knowledge graph & ontology — schema-as-graph for grounded AI the Fabric IQ / Foundry IQ direction

WhatA knowledge graph built entirely from the code layer — table relationships, per-column definitions, join paths — for a warehouse with no foreign keys. It powers natural-language query answering and automated report generation: the ontology layer between the warehouse and the agents, so schema context stops being hand-fed into every prompt. Demoed to leadership.

Why it mattersMicrosoft's Fabric IQ and Foundry IQ announcements map almost one-to-one onto this design — grounding agents in a semantic layer instead of raw schema. I evaluated both at Microsoft's AI Innovation Day and folded them into our grounding roadmap.

Security, observability & reliability
Security Security architecture — designed, and measured quarterly APIM as the single front door

DesignLeast-privilege integration identities (after auditing an over-broad access grant), bulk secret centralization into Key Vault with managed identities, private ILB workflow triggers with API Management as the only public surface, Front Door / WAF rule tuning, and secret-rotation discipline.

MeasurementSecurity as a recurring habit, not a launch checklist: a per-application assessment framework — dimensions defined first, scored application by application, revisited quarterly.
